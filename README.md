# Design Audit MCP Server

A stack-agnostic MCP (Model Context Protocol) server for design auditing, refactoring, and UI/UX code generation with design intelligence.

## Features

- **Deterministic Extraction**: AST-based parsing for JSX/TSX/HTML with comprehensive design element extraction
- **Design Critique**: Weighted scoring system (0-5) across 10 design categories
- **Automated Refactoring**: Deterministic fixes for spacing, accessibility, and component replacements
- **Code Generation**: Generate components and layouts following design rulesets
- **Extensible Rulesets**: JSON-based rules for brand tokens, accessibility, responsive design, and more

## Installation

```bash
npm install
npm run build
```

## Usage

Start the MCP server:

```bash
npm start
# or
./start.sh
```

## MCP Tools

### `design_extract`
Extract design elements from code (components, layout, spacing, typography, imagery, accessibility).

### `design_get_ruleset`
Get the current design ruleset configuration.

### `design_audit`
Run a complete design audit: extract, critique, and score design elements.

### `design_refactor`
Apply deterministic fixes to refactor code based on audit results.

### `design_generate`
Generate new component or layout code following the design ruleset.

### `design_apply_patch`
Apply patches generated by LLM to a file.

## Project Structure

```
src/

├── rules/          # Ruleset definitions and loader
├── critique/       # Design critique schema and scoring
├── refactor/       # Code refactoring and patch application
├── generate/       # Component and layout generation
├── types/          # TypeScript type definitions
└── utils/          # Logging and error handling
```
